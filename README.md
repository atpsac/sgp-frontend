# Amazonas Trading Perú S.A.C. - Sistema de Pesaje en Tiempo Real

Sistema web desarrollado para **Amazonas Trading Perú S.A.C.**, empresa exportadora de cacao, orientado al control, registro y monitoreo de procesos de pesada en tiempo real.

El sistema permite gestionar información operativa relacionada con el ingreso, pesaje y control de productos, facilitando la trazabilidad del cacao y optimizando los procesos internos de la empresa.

## Descripción del proyecto

Este proyecto corresponde a una plataforma administrativa para el control de pesajes en tiempo real. Está desarrollada con Angular y permite visualizar, registrar y administrar información clave del proceso de recepción y control de cacao.

El sistema está pensado para apoyar operaciones como:

- Registro de pesadas.
- Control de ingreso de productos.
- Monitoreo de peso en tiempo real.
- Gestión de información de proveedores o clientes.
- Control de trazabilidad del cacao.
- Administración de usuarios y accesos.
- Reportes operativos.

## Empresa

**Amazonas Trading Perú S.A.C.**

Empresa dedicada a la exportación de cacao, enfocada en la gestión, comercialización y trazabilidad de productos agrícolas para mercados nacionales e internacionales.

## Tecnología utilizada

Este proyecto fue generado con [Angular CLI](https://github.com/angular/angular-cli) versión **20.3.7**.
